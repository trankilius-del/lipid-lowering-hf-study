# lipid-lowering-hf-study
Statistical analysis plan for the study on lipid-lowering therapy in heart failure.


This repository contains the statistical analysis plan (SAP) and code for the manuscript:

"Lipid-Lowering Therapy in Heart Failure in Contemporary Clinical Practice"

Due to Swedish register-based data restrictions, individual-level data cannot be shared.

## Contents
- SAP: Statistical analysis plan
- Code: Analysis scripts (if applicable)

## Transparency
This repository is provided to enhance transparency and reproducibility of the study.
